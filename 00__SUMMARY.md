# AZL — ROOT SUMMARY

Этот файл — единая точка входа **для ассистента**.

## START (в начале каждого нового чата)
1) Открыть этот ROOT SUMMARY.
2) Открыть `Assistant Guides/00__SUMMARY.md` и при необходимости перечитать правила.
3) Дальше ходить по summary-дереву: сначала `00__SUMMARY.md` нужной папки, затем точечно открывать файлы.

## Ссылки
- `Assistant Guides/00__SUMMARY.md` — модульные гайды и правила работы

## Ветки контента
- `Golarion/00__SUMMARY.md` — общий лор мира: локации, фракции, религия
- `Сюжет кампании/00__SUMMARY.md` — сюжет, арки, сцены и материалы ведущего
- `NPC/00__SUMMARY.md` — NPC (МПС) кампании: персонажи мира, не игроки
- `PC/00__SUMMARY.md` — персонажи игроков этой кампании
- `Sessions/00__SUMMARY.md` — заметки по сессиям: итоги, хвосты, планы, ссылки на сцены
- `Glossary/00__SUMMARY.md` — глоссарий ассистента: термин/имя → ссылка на «каноничную» страницу
- `Болезни/00__SUMMARY.md` — болезни мира (Лужи Абсалома и др.)

## Примечание
- Все папки контента должны иметь `00__SUMMARY.md`, в котором есть ссылки на подпапки/файлы уровня ниже.
- После генерации/правок: если появились новые значимые термины/имена/фракции/локации/механики — обновить `Glossary`.
