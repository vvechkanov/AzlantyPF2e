# Session Pipeline — полная обработка сессии PF2e

Один прогон: чанки → транскрипт → рекап → обновлённый словарь. Wall time ~15-20 минут для сессии ~450KB сырых чанков.

## Когда использовать

Триггеры: «обработай сессию N», «запусти пайплайн по сессии N», «сессия N готова», «прогон сессии», «полная обработка сессии», «весь конвейер».

**Не запускать** если:
- Чанков ещё нет в папке (попроси сначала сделать WhisperX-нарезку)
- Пользователь явно прислал один чанк руками — используй `session-clean`

## Входные данные

Папка: `Cессии/Сессия-N/chunks/` (на Windows, вне Obsidian)

Структура:
```
chunks/
  000_context.txt    # манифест: source, speakers, notes (overlap-info)
  manifest.json
  0001.txt           # чанк ~50KB
  0002.txt
  ...
  000K.txt           # последний может быть меньше
```

## Выходные данные

```
Sessions/SessionN/ПС{N}_transcript.md   # ~200KB, склеенный транскрипт
Sessions/SessionN/ПС{N}_recap.md        # ~60KB, рекап по шаблону С6
Glossary/Transcription_Dictionary.md    # обновлён новыми NPC + артефактами
```

И промежуточные (можно потом удалить):
```
chunks/cleaned/000K_clean.md            # K cleaned файлов
```

## Пайплайн — 7 этапов

### Этап 0: Подготовка

1. Прочитай `000_context.txt` — нужен список speakers
2. Прочитай `Glossary/Transcription_Dictionary.md` — словарь имён (зашьёшь в промпты)
3. Прочитай `Assistant Guides/11__Очистка_транскрипции.md` — правила (если ещё не в контексте)
4. Создай папку `chunks/cleaned/` через `mkdir -p`
5. Проверь, что папка `Sessions/SessionN/` существует (создай если нет)
6. Запусти TodoWrite со списком этапов

### Этап 1: 9 параллельных Sonnet-чистильщиков

Запусти **K параллельных Agent** в **одном сообщении** (K = число чанков, обычно 9).

Параметры каждого Agent:
- `subagent_type: general-purpose`
- `model: sonnet`
- `run_in_background: true`
- `description: "Clean chunk 000K"`

Шаблон промпта — в файле `prompts/cleaner.md` этого скилла. Подставь `{CHUNK_NUM}` (например `0001`).

Wall time: каждый ~3-5 минут параллельно, всего ~6 минут.

### Этап 2: Merge через Python

Когда все K чистильщиков вернули отчёты, запусти Python-скрипт merge. Скрипт — в `scripts/merge.py` этого скилла. Запуск:

```bash
python /path/to/skill/scripts/merge.py N
```

Где `N` — номер сессии. Скрипт:
- Читает `chunks/cleaned/000*.md`
- Удаляет блоки `# UNCERTAINTIES`
- Удаляет YAML-фронтматтер (если есть)
- На каждом стыке `i → i+1` ищет marker (определён в скрипте) и обрезает overlap
- Применяет normalize-замены (большая таблица WhisperX → канон)
- Пишет финальный `Sessions/SessionN/ПС{N}_transcript.md`

Если скрипт не находит marker — он выводит WARN. В этом случае посмотри сам и предложи fallback.

### Этап 3: Подчистка стыков

После merge — типовые правки на стыках через Edit. Проверь грепом:

```bash
grep -n "^### " Sessions/SessionN/ПС{N}_transcript.md
```

Типовые проблемы:
1. **Микрозаголовок-заглушка** — заголовок + 1 строка текста перед полной сценой. Удалить заголовок.
2. **Артефакт `*[чанк обрывается]*`** — убрать; склеить две реплики одного говорящего в одну.
3. **Дубль начала сцены** — два заголовка `###` подряд + повторяющийся первый абзац. Убрать первый заголовок и абзац, оставить второй.
4. **Двойной `---` подряд** — оставить один.
5. **Заголовок устаревшего OOC-блока** — если последний чанк (только OOC) дублирует фидбэк из предыдущего, слить блоки.
6. **Косметика заголовков** — переименуй неточные («Дорога в Абсалом» → «Путь к таверне», если партия уже в городе).

Применяй через Edit'ы в одном сообщении (параллельно).

### Этап 4: 3 параллельных QA-агента

Разбей транскрипт на 3 примерно равных сегмента (по количеству строк) и запусти 3 Agent.

Параметры:
- `subagent_type: general-purpose`
- `model: sonnet`
- `run_in_background: true`
- `description: "QA segment K"`

Шаблон промпта — в `prompts/qa.md` этого скилла. Подставь номер сегмента и диапазон строк.

Каждый агент возвращает список `[FIX]` (уверенные) и `[CHECK]` (спорные) правок с готовыми `old_string`/`new_string` для Edit.

### Этап 5: Применение QA-правок

Из 3 отчётов собери сводный список правок. Применяй:
- Все `[FIX]` → Edit'ами параллельно в одном сообщении
- Каждый `[CHECK]` → реши по контексту. Если уверен — применяй. Если нет — спроси пользователя ОДНИМ сводным сообщением (не по одной).

**Важно:** перед каждой `[FIX]` убедись, что предложенная замена не противоречит твоему знанию канона PF2e и/или ответам пользователя ранее в сессии. Например, если пользователь подтвердил, что слово «Нефис» правильное — не заменяй на «письмо Нефис».

### Этап 6: Рекап

В основном чате (контекст свежий — все 9 cleaned-файлов прочитаны) напиши `Sessions/SessionN/ПС{N}_recap.md` по шаблону **Sessions/Session6/ПС6_recap.md**.

Структура рекапа:
1. Заголовок и дата по календарю Голариона
2. Краткое введение (1-2 абзаца, контекст с предыдущей сессии)
3. Сцены (заголовки `###`, диалоги с прямой речью персонажей)
4. Раздел `## Итоги сессии`:
   - **Боёвок** (число, краткое описание)
   - **Лут получен** (детально: что, у кого, за сколько, в каком городе)
   - **Лут потрачен** (детально)
   - **Левелап** (явно объявлен или нет)
   - **Состояния** (болезни, эликсиры, нарративные состояния)
   - **Изменения отношений и мира** (по каждому ключевому NPC)
5. Раздел `## Хронология сессии` (таблица: время — событие)
6. Раздел `## На горизонте` (планы на следующую сессию)
7. Раздел `## GM-заметки` (что сработало, что обдумать)

**Критично сохранить:** все денежные суммы (лут), имена NPC, броски, ключевые решения. Каждая боёвка — отдельно: с кем, нон-летал или нет, кто упал, что сработало/не сработало.

### Этап 7: Обновление словаря

Обнови `Glossary/Transcription_Dictionary.md`:

1. **Новые NPC** — добавь в соответствующие разделы. Если NPC в локации, которой ещё нет — создай новый раздел.
2. **Новые локации** — добавь в `## Локации` или подходящий раздел.
3. **Новые термины/языки/божества** — в соответствующие разделы.
4. **Таблица WhisperX → канон** — добавь новые артефакты в конец файла. Эта таблица помогает следующим прогонам.

Что в таблицу: только повторяющиеся артефакты, не одноразовые ошибки распознавания.

## Итоговый отчёт пользователю

В конце пайплайна выдай:
- Ссылки на 3 файла-артефакта (transcript, recap, dictionary)
- Кратко: сколько правок применено, сколько [CHECK] под вопросом
- Список новых NPC из сессии (для удобства)
- (Если есть) список вопросов пользователю по неоднозначностям

## Что НЕ делать

- **Не пытайся merge через одного субагента** — стрим-вотчдог рвёт при выводе >100KB. Используй Python-скрипт.
- **Не пиши в файл от субагента-QA** — пусть возвращает список правок, ты применяешь Edit'ами сам. Безопаснее.
- **Не сжимай реплики** в рекапе — IC-цитаты сохраняй дословно, как в транскрипте.
- **Не выдумывай каноничные имена** — если в Pathfinder каноне нет, спроси пользователя или ищи в его Obsidian-волте через Grep.

## Файлы скилла

- `prompts/cleaner.md` — шаблон промпта чистильщика (Этап 1)
- `prompts/qa.md` — шаблон промпта QA-агента (Этап 4)
- `scripts/merge.py` — Python-скрипт merge (Этап 2)
- `scripts/normalize.py` — модуль с replace-таблицей (используется merge.py)
