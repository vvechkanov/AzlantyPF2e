# Промпт чистильщика чанка (Этап 1)

Используется в Agent (model=sonnet, run_in_background=true). Подставь `{N}` — номер сессии, `{CHUNK_NUM}` — номер чанка (например `0001`).

---

Ты очищаешь сырой транскрипт PF2e-сессии (WhisperX → текст). Это сессия {N} кампании «Азланти». Делаешь это для большой склейки — твой результат потом сольют с другими очищенными чанками.

## Что делать

1. Прочитай входной чанк: `C:\DND\Азланти\Cессии\Сессия-{N}\chunks\{CHUNK_NUM}.txt`
2. Очисти по правилам ниже
3. Запиши результат в файл: `C:\DND\Азланти\Cессии\Сессия-{N}\chunks\cleaned\{CHUNK_NUM}_clean.md`
4. В конце результата — блок `# UNCERTAINTIES` с пронумерованным списком неясных мест (если есть)

## КРИТИЧЕСКИ ВАЖНО

- **НЕ СЖИМАЙ.** Чанк ~30-50KB. После очистки будет ~20-40KB. Это нормально для одного Write. Обрабатывай построчно, реплику за репликой. Если кажется «слишком много текста» — это нормально, не сворачивай реплики в пересказ.
- **IC-реплики никогда не сворачивай в курсивный пересказ от 3-го лица.** Каждая in-character реплика остаётся в формате `**Имя (роль):** прямая речь`. Это критическое правило — нарушение убивает голос персонажей.
- **Чанки специально перекрываются** на стыках. Обрабатывай ВЕСЬ свой чанк целиком, ничего не обрезай в начале/конце — дедуп overlap'ов сделает merge-шаг отдельно.
- **Не сглаживай голос персонажа.** Сохраняй характерные междометия, паузы, авторские формулировки игроков. Убираем только запинки WhisperX и явные ошибки распознавания.
- **Не «исправляй» GM-сленг Володи.** Слова **опорта/опорту** (= Attack of Opportunity), **редкон/редконить** (= retcon), **пачка** (= партия PC), **сничу/снич** (= спишу) — намеренные. Не заменяй их на «правильные» формы. Полный список — в `Glossary/Transcription_Dictionary.md` блок «GM-сленг».

## Правила очистки — ТРИ УРОВНЯ

### 1. Сохраняем как есть (in-game / in-character)
- Весь отыгрыш, описания ГМ, диалоги
- Боёвка: броски, тактика, решения, описания атак
- **Покупки:** кто что купил, у кого, за сколько, в каком городе. Системные строки `Предмет N Цена`, `Стандартное`, `[ЧАТ] <NPC>` собирай в осмысленную запись типа: «Микаэль купил у Освальда Меррика [предмет] за [цена]»
- **Travel Calculator** (Расстояние) — если партия планирует маршрут, расстояние/время важны
- **Weather Forecast** (Region/Season) — задаёт сцену, оставляй кратко
- **Extempore Effects / баффы** (Name, Actor, Expired, After duration, Reapply Эффект) — если эффект влияет на боёвку → оставляй; если просто фон без последствий → опускай
- Споры о механике сворачивай в итог: `[решили: не застигнут врасплох]`

### 2. Суммаризуем коротко с пометкой `*[OOC: ...]*` (out-of-character, но связано с игрой)
- Обсуждения тактики на мета-уровне
- Споры о правилах, билдах, бонусах
- Например: 10 минут «кто кого хилит» → одна строка `*[OOC: партия ~10 минут обсуждала порядок ходов и кто хилит Бель]*`

### 3. Удаляем полностью (оффтоп)
- Что поели, новости, мемы
- Технические проблемы (звук, микрофон, реконнекты)
- Перерывы, болтовня ни о чём
- Пост-сессионная рефлексия

**Ключевое:** не выкидывай системные строки автоматически по имени отправителя — смотри на содержание.

## Формат вывода

```
**Вова (ГМ):** ...описание ГМ или его слова...

**Сеня (Микаэль):** Прямая речь Микаэля.

*Действие или описание действия персонажа курсивом.*

*[Бросок: атлетика, результат 18.]*

---

### Заголовок сцены (по смыслу — смена локации/фокуса)

...
```

- `**Имя (роль):**` — игрок (персонаж). Если OOC — `**Имя (OOC):**` или `*[OOC: ...]*`
- Действия и описания — курсивом
- Броски и решения механики — `*[...]*`
- Между сценами — `---`
- Заголовки сцен ставь по смыслу: смена локации, смена фокуса, новая встреча

## UNCERTAINTIES

В конце файла, если есть неясные места:

```
# UNCERTAINTIES

1. Строка ~XX: «...» — непонятно, кто говорит / что значит / IC или OOC. Контекст: ...
2. ...
```

Если всё чисто — блок не пиши.

## Готов?

Поехали. Прочитай чанк, обработай, запиши в выходной файл. Когда закончишь — верни короткий отчёт: сколько строк на выходе, есть ли UNCERTAINTIES (количество), какие основные сцены в чанке.
