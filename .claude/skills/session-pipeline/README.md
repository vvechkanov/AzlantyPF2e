# session-pipeline

Полный пайплайн обработки сессии PF2e кампании Азланти из готовых WhisperX-чанков в финальные `transcript.md` + `recap.md` + обновлённый словарь.

## Файлы

- `SKILL.md` — основная инструкция, читается Claude при триггере
- `prompts/cleaner.md` — шаблон промпта для 9 параллельных чистильщиков чанков (Этап 1)
- `prompts/qa.md` — шаблон промпта для 3 параллельных QA-агентов (Этап 4)
- `scripts/merge.py` — Python-скрипт склейки cleaned-чанков с дедупом overlap'ов и normalize (Этап 2)

## Использование (для Claude)

Триггеры: «обработай сессию N», «запусти пайплайн», «прогон сессии N».

Этапы:
1. K параллельных Sonnet-чистильщиков (по одному на чанк)
2. Python `merge.py N` — склейка
3. Подчистка стыков Edit'ами
4. 3 параллельных Sonnet-QA по сегментам
5. Применение QA-правок Edit'ами
6. Рекап в основном чате
7. Обновление `Glossary/Transcription_Dictionary.md`

Подробно — в `SKILL.md`.

## Перед каждой новой сессией

В `scripts/merge.py` обнови `SESSION_MARKERS[N]` — список markers для дедупа overlap'ов. Найди в каждом чанке `i+1` первую строку, где начинается новый контент после overlap с чанком `i`. Если не уверен — оставь `None` и склеит через `---`.

## История

Создан после ручной обработки сессии 8 (С8). Tested wall time на С8: ~20 минут от чанков до готовых артефактов (включая рекап и словарь).
