# Session to Video — видео-пересказ сессии

Конвейер: готовый текст Тироса → раскадровка → арты → озвучка → монтаж.
Первый выпуск (С0 «Хартвик») занял неделю по вечерам, 7 минут хронометража, 36 кадров.

## Роли

| Кто | Что делает |
|-----|-----------|
| **Claude** | раскадровка, тайминги, промпты на арты, монтажный лист-артефакт, разноска файлов по папкам, консультации по Resolve |
| **Влад** | генерация артов (Gemini / ChatGPT), запись озвучки (ElevenLabs), музыка (Suno), монтаж (DaVinci Resolve) |

Claude **не генерит арты сам** — у Влада лучше выходит, потому что он держит референсы в чате генератора и правит на лету. Claude пишет промпты и складывает результат.

## Структура проекта

Всё живёт **вне волта** — картинки и аудио раздули бы git-репозиторий.

```
C:\Azlanti\Video\
   SessionN\
      shot01_описание.jpg        кадры, оригиналы как есть
      shot02_описание.png
      _старые\                   вытесненные версии, не удалять
      art\                       промежуточные варианты
      audio\                     озвучка, имена по кадрам
         _music\                 музыкальная библиотека
         _тексты_на_запись.txt   что осталось записать
      video\                     видеоклипы
      paper\                     пустые листы пергамента
         frames\                 рамки с прозрачной серединой
      render\                    готовые файлы
   References\                   портреты персонажей, кропы сцен
```

**Файлы не трогать**: не апскейлить, не кропать, не пережимать. Класть оригиналы как пришли от генератора — Resolve сам масштабирует при рендере, а предварительное растягивание даёт двойную интерполяцию.

**Не перезаписывать файл под тем же именем**, если он уже импортирован в Resolve — редактор кеширует и покажет старую версию. Давать новое имя с суффиксом `_v2`.

## Порядок работы

### 1. Раскадровка

Взять текст Тироса и порезать под видеотайминг. Не по абзацам, а по кадрам.

Правила:
- Кадр держит внимание **8–20 секунд**. Всё, что длиннее 25 на одной картинке, дробить на планы: общий → лицо → деталь.
- Расчёт хронометража: **2,3 слова в секунду**. По факту записи выходит на 15–18% длиннее — закладывать сразу.
- **Хронология важнее композиции текста.** Тирос в отчёте группирует по темам (сначала всё про одного, потом про еду, потом пометка про молитву), но на экране это выглядит как скачок. Переставлять в порядок событий и править связки.
- После любой перестановки **проверять висячие местоимения**. «Она слушала её», «Анканто это заметил», «спор, к которому он готовился» — всё это ломается, когда между фразами появляется склейка. Ловится только вычиткой подряд.

Формат файла — `Sessions/SessionN/Пересказ-видео__раскадровка.md`, по кадрам:

```
### Кадр 12 · ~22 с
**[АРТ 11]** что нарисовано
**[ТИТР]** если есть
**[КАМЕРА]** движение при монтаже
**[ЗВУК]** имена mp3 с длительностями
**[ТЕКСТ]**
сам текст на озвучку
```

### 2. Промпты на арты

Отдельным файлом `Пересказ-видео__промпты.md`, чтобы раскадровка читалась как монтажный лист.

**Писать промпты целиком**, без сокращений вида «та же шапка» — Влад копирует их по одному.

Правила стиля вшиты в каждый промпт, см. `references/prompt-rules.md`.

### 3. Арты

Влад генерит, Claude забирает из Загрузок и раскладывает.

Приёмы, которые работают:
- **Цепочка в одном чате** для кадров, которые должны совпасть по стилю (интро, соседние планы). Первый промпт полный, дальше «now the second image of the same set, same style».
- **Сцена как референс**: сгенерировать интерьер один раз, потом кропать его зоны и досаживать персонажей. Дом будет одним и тем же во всех кадрах.
- **Накопительная сцена**: к кадру с одним персонажем досаживать второго, к двум — третьего. Стол заполняется, лица не меняются.
- **Не просить «приблизь»** — генератор не умеет операций над картинкой, он рисует заново. Описывать конечный кадр.
- **Две правки максимум.** Третья доработка подряд уводит стиль: цвет вымывается, линия становится векторной. Дальше генерить начисто.

### 4. Озвучка

ElevenLabs, настройки в `references/voice.md`.

- Записывать **короткими фразами**, по одному-двум предложениям на файл. Паузы ставятся в Resolve, а не тегами.
- Claude забирает mp3 из Загрузок и переименовывает по кадрам: `shot12_a.mp3`, `shot12_b.mp3`.
- Список несделанного держать в `audio/_тексты_на_запись.txt`.

### 5. Монтажный лист

Артефакт со всеми кадрами: картинка, движение камеры, текст, файлы озвучки с секундами. Собирается скриптом из раскадровки, см. `scripts/build_board.py`.

Публиковать через Artifact, обновлять по тому же file_path — ссылка сохраняется.

### 6. Монтаж

Настройки Resolve и приёмы — в `references/resolve.md`.

## Что не работает — проверено

**AI-апскейл артов.** Upscayl и подобные не увеличивают, а перерисовывают: вычищают зерно бумаги и акварельную размывку, линия становится векторной. На нашем стиле это смена манеры. Отдавать в Resolve оригиналы.

**Анимация людей.** Из трёх пробных клипов развалился ровно тот, где в кадре человек — фигура растворялась. Река и вспышка живут прекрасно. Правило: **анимируем стихии, не людей**. Огонь, вода, дым, свет — да; лица, руки, фигуры — нет.

**Параллакс.** Не делать. У рисунка нет глубины по определению, слои разъедутся и сломают иллюзию страницы. Движение камеры по листу — можно, разбор листа на планы — нет.

**Теги пауз в тексте озвучки.** В Fish Audio работают, но дают слишком длинные паузы. В ElevenLabs v2 не работают вовсе. Резать на файлы.

**Speech-to-Speech для русского.** Тембр переносит, речь превращает в кашу — виновата обработка игрового микрофона и высокая Stability. Если пробовать снова: сырой сигнал без шумодава, Stability 0,30–0,40.

## Открытые вопросы

- **Голос.** Носой 3 в ElevenLabs звучит роботизированно (фидбэк жены Влада). Вероятная причина — Stability 0,70. Пробовать 0,40–0,50 и Style 0,45. Альтернатива — клонировать тот же голос в Fish Audio, где есть контроль на уровне слова.
- **Разрешение.** 1080p выбрано из-за клипов Veo 720p из приложения Gemini. Во Flow тот же Veo умеет 1080 и 4K — если перегенерить клипы там, можно уйти в 4K.
