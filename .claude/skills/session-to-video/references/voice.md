# Озвучка — голос Тироса

## Настройки ElevenLabs

```
голос         Носой 3
модель        Eleven Multilingual v2
speed         1.04–1.08
stability     0.70   ← под вопросом, см. ниже
similarity    0.70
style         0.30
speaker boost вкл
формат        MP3 44.1 kHz / 128 kbps
```

Настройки читаются прямо из имени скачанного файла: `sp104_s70_sb70_se30` — скорость 1,04, стабильность 70, похожесть 70, стиль 30.

**Стабильность 0,70 даёт роботизированную интонацию** — фидбэк от жены Влада на первом выпуске. Пробовать 0,40–0,50 и Style 0,45. Риск: голос может слегка гулять между файлами, но файлы короткие и разделены паузами, так что вариативность прочитается как живость.

Почему v2, а не v3: v3 экспрессивнее, но менее предсказуем на длинных формах. Для семиминутного монолога важнее, чтобы голос не поплыл.

## Что модель не умеет

**Audio tags** (`[sighs]`, `[pause]`) — фича v3, в v2 либо игнорируются, либо зачитываются вслух. Паузы ставить в Resolve.

**Фонемные теги** — поддерживаются только Flash v2 и v3. В Multilingual v2 словарь произношения принимает только alias-замены, то есть подмену написания.

**Ударения в косвенных падежах.** Главная головная боль. «С Вареном» модель читает как отглагольную форму, с ударением на второй слог. Три обхода, по возрастанию надёжности:

1. Перестроить фразу в именительный: «Варен, Анканто и Микаэль воевали» вместо «воевали с Вареном».
2. Комбинирующий акут: `Ва́рен` — срабатывает через раз.
3. Подмена гласной: `ВАрын` — работает надёжнее всего, звучит нормально.

**Буква ё** — проблемная, модель на ней спотыкается. Первым делом пробовать замену на «е»: `посерьезнела` вместо `посерьёзнела`. Если не помогает — менять слово.

**Интонация последнего слова** задаётся тем, что идёт **после** него. Короткое предложение в конце генерации модель тянет вверх, потому что не знает, что дальше ничего нет.

Лечится хвостом, который потом отрезается:
```
Рутинное расследование реестровой аномалии. Определённо. Запись окончена.
```

Если слово может быть прочитано как вводное («определённо, это было...»), хвост не спасёт — надо превратить его в ответ на вопрос:
```
Рутинное ли это расследование реестровой аномалии? Определённо.
```
Вопрос потом вырезается.

Последнее средство — питч в Resolve: разрезать слово, у последнего слога поставить Тональность −1…−2 полутона, стык замазать кроссфейдом. Плюс затухание громкости на хвосте.

## Перечисления

Точки вместо запятых дают ровные равные акценты — протокол вместо меню:

```
было:  Запечённая гречка с мясом, овощной салат, свежий хлеб, нарезки сыра.
стало: Запечённая гречка с мясом. Овощной салат. Свежий хлеб. Нарезки сыра.
```

Нарастающие перечисления строить повтором первого слова — модель подхватывает ритм сама:
```
Один молчит. Один светится. А один открывает дверь незнакомцам…
```

## Нарезка и паузы

Записывать по одной-две фразы на файл. Паузы ставить на таймлайне:

```
между фразами внутри кадра     0,3–0,5 с
на смене кадра                 0,6–1,0 с
на стыке частей                1,5–2,0 с
драматическая пауза            2,0 с
```

Драматические места первого выпуска: после «Спросила, приходилось ли убивать людей», после слова «Пометка», перед финальным «Определённо».

Паузы добавляют к хронометражу 40–60 секунд на семь минут.

## Именование

`shot12_a.mp3`, `shot12_b.mp3` — по кадру и порядку внутри кадра. Длительность держать в раскадровке, а не в имени: имена стабильнее.

Списки несделанного — `audio/_тексты_на_запись.txt`, с настройками голоса в шапке.

## Альтернативы, если менять движок

Менять голос между выпусками нельзя — это идентичность канала. Решать до второго ролика.

**Fish Audio S2** — русский держит, есть клонирование и контроль на уровне слова. Голос Носоя можно клонировать по уже записанным файлам: семь минут чистой речи — готовый датасет. Тембр сохранится, появится управление ударениями.

**Yandex SpeechKit** — ударения знаком `+` и SSML-паузы штатно. Но голоса только готовые дикторские; клонирование (Brand Voice) стоит от 9000 ₽.

**Silero** — бесплатно, локально, ударения через `+`. Голоса простенькие, но независимость от чужих лимитов.
