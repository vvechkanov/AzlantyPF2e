# Session → Wiki — внесение сессии в публичную вики

Один прогон: транскрипт сессии → структурный разбор → обсуждение с Владом → правки вики → сводка со ссылками → коммит → подтверждение → пуш.

## Контекст сайта

- **Репо вики:** `C:\AI-assistant\wiki\` (репо `vvechkanov/azlanti-wiki`, ветка `main`).
- **Контент:** прямо в `C:\AI-assistant\wiki\public\*.html` (без сборки). CSS — `public/assets/wiki.css`, JS/навигация/поиск/счётчики — `public/assets/wiki.js`.
- **Деплой:** `git push` → GitHub Actions → живёт на `wiki.vlad-vechkanov.com` (и `.link`). Руками ничего заливать не нужно. Деплой ~30 сек.
- **UTF-8 без BOM, LF.** Массовые правки — Python-скриптом с `PYTHONIOENCODING=utf-8` (cp1252-баг stdout на Windows), пиши `newline="\n"`.

## Жёсткие правила (читать ПЕРЕД работой)

**Сначала прочитай ЦЕЛИКОМ эти файлы памяти** (не по индексу — сами файлы; путь `C:\Users\vechk\.claude\projects\C--DND-sync-Sync-Obsidian-PF2e-----------------\memory\<name>.md`): `feedback_wiki_voice`, `feedback_wiki_card_guide`, `feedback_wiki_show_dont_tell`, `feedback_wiki_event_density`, `feedback_leads_definition`. Ключевое из них продублировано ниже и в Шаге 3 с примерами — но свежий агент часто НЕ применяет правила, если не прочитал первоисточник. Прочитай.

Вся вики — **только то, что знают игроки**. Абсолютно строго. Подробный свод — в памяти:
- [[feedback_wiki_card_guide]] — единый чек-лист письма карточки. **Читать и давать сабагентам.**
- [[feedback_wiki_names_canon]] — имена/фамилии из канонных волт-файлов, не по слуху (голос искажает: «Йоран» → канон **Йорен Орувиэль**, «Марилла» → **Дом Морилла**). Помечать «партия расслышала как…» при желании.
- [[feedback_wiki_event_density]] — 2–4 смысловых пункта на сессию в «События», не построчно. Влад постоянно ловит на переподробности — сжимать. На локациях — никаких разделов «Оборона (СN)»/«После боя»: это пересказ сессии, всё в компактные «События».
- [[feedback_leads_definition]] — зацепка = ниточка, за которую можно потянуть (задача/вопрос/срок/непосещённый человек), а НЕ каталог фактов. Место само по себе, решённый итог, «в СN сделаем», дубли — не зацепки. leads держать коротким.
- [[feedback_no_neletalno]] — не писать «нелетально»; «не убив никого», «оглушила».
- [[project_canon_makrakery]] — стража Луж = **Макракеры**, не «Муракаки».
- [[project_secrets]] — Круг Syrvas, Onyx Alliance и прочие ГМ-тайны НЕ в player-facing. Секрет, случайно всплывший в тексте (напр. инсигния ордена PC), **замазывать** `.gm-redact` — и НЕ класть реальный секрет в HTML (внутри спана — шутка-заглушка, не канон).
- **PC не пишем** карточками и не даём им «События»: Микаэль, Анканто, Киран, Гельдала, Бель, Самум — игроки.
- **Транскрипт > рекап.** Правки строить на транскрипте (source of truth), рекап — только опорой. Делать пересказ с пересказа — плохо.

## Шаг 1. Разбор транскрипта (фоновый агент)

Проверь, что есть `Sessions/Session{N}/ПС{N}_transcript.md`. Запусти **фоновый** `Agent` (Explore, model **sonnet**, `run_in_background: true`) — пусть прочитает **весь транскрипт построчно** (рекап — сверкой), сверит с `C:\AI-assistant\wiki\public\` (glob `npc-*`, `loc-*`, `org-*`) и каноном волта (`NPC/`, `Golarion/`), и вернёт структурно:

1. **Канва** (5–8 пунктов): что произошло, где, внутриигровая дата (начало/конец), где партия в конце.
2. **Новые NPC**: канон-имя, где встретили, есть ли уже файл, достоин ли карточки. Верни ОТДЕЛЬНО три вещи (не смешивать): **(а) суть/портрет** — кто это в 1–2 предложениях (роль, чем важен); **(б) что было в сцене** — сырьё для «События»; **(в) лор, который NPC рассказал** (устройство мира, чужая предыстория, механика) — помечай «→ на профильную страницу», это НЕ для карточки самого NPC.
3. **События существующим npc-*/loc-***: 1 строкой, по-игроцки, только значимое.
4. **Локации**: новые (нужна ли страница) и правки существующих.
5. **Зацепки**: новые, закрытые/продвинутые, таймеры. Каждую формулируй как ДЕЙСТВИЕ («пойти к X / сделать Y / успеть к сроку»), а не как факт/предмет/противника — см. тест зацепки в Шаге 3. Помечай, что закрылось/продвинулось, я решу.
6. **Лендинг**: где партия сейчас, дата на конец, короткое «где мы сейчас», номер следующей сессии.

Каждый пункт — с опорной цитатой и номером строки. В промпте явно: не выдумывать, не тащить ГМ-планы/тайны, канон-имена из волта.

## Шаг 2. Обсуждение с Владом (обязательно)

Когда агент вернулся — **не пиши сразу**, покажи Владу разбор и **спорные решения**:
- какие NPC заводить полной карточкой, кого — только упоминанием, кого — org-страницей;
- где портрет (проверь сервер), где **✕** (встречен, арта нет), где **❔** (не встречен);
- канон-написания имён (флагни расхождения слух↔канон);
- что «канон-утечка, на игре не звучало» → вырезать;
- твои дополнительные правки, которые видишь.

Дождись ответов. Влад решает про файлы/картинки/тайны.

## Шаг 3. Внесение правок

**Новые карточки** — по шаблону существующих (`npc-keina.html` — эталон NPC, `org-ormus.html` — эталон org без портрета). Анатомия: `page-head` (kicker/h1/lede/meta-row badges) → `entry` с `prose` (lead + разделы Внешность/События/Связи) + `aside` (portrait-wrap + infobox dl).

> ### ⚠️ ГЛАВНОЕ ПРО lead КАРТОЧКИ: это ПОРТРЕТ, а не пересказ сцены
> Первый абзац (`.lead`) — ответ на устный вопрос «кто это?»: роль/место, суть, чем важен, характерные повадки — связным рассказом ГМа в **3–6 предложений**. Это НЕ протокол встречи и НЕ дневник сессии.
> - ✗ **Плохо (пересказ сцены):** «Встречает гостей поклоном… Когда Бель сослалась на диету, ответил… позвал Горбика и предложил… Спас положение паук Гельдалы, король увлёкся репетицией…» — это поминутный отчёт о встрече.
> - ✓ **Хорошо (портрет):** «Король гоблинов из старого театра в Лужах. Эксцентричен: говорит о себе в третьем лице, корона из вилок с бубенчиками, каждый третий день ставит спектакли. Гостеприимство ритуальное — пикули с ржавой вилки. К людям расположен.»
>
> Правила:
> - Конкретные реплики / поминутка встречи → в **«События»** (2–4 сжатых пункта), НЕ в lead.
> - Лор, который NPC рассказал (устройство мира, чужая предыстория, механика предмета) → на **профильную страницу** (лор/артефакт) + ссылка. НЕ вываливать лор-лекцию в карточку.
> - Начинай с сути/роли, не с внешности. Цитаты вкатывай в строку, не блоком.
> - Длина `.lead` — 3–6 предложений. Абзац на 1000+ символов = это уже не портрет, переделывай.
- Портрет: `<img class="portrait" src="https://vlad-vechkanov.com/azlanti/portarits/<slug>.webp" ...>` (папка `portarits` — опечатка намеренная). Проверяй наличие `curl -A "Mozilla/5.0"` (HEAD/urllib сервер режет).
- Нет арта, встречен → `<div class="placeholder-img tall none"></div>` (✕). Не встречен → `...tall unknown` (❔).
- Chips: `chip wl` (NPC), `chip wl loc` (локация), `chip` без href (некликабельно, нет страницы), `chip ext` (внешняя ссылка — боги/страны, синим).

**Правки существующих**: дописать «События» (сжато!), обновить lead/инфобокс, при первом посещении локации — пометить «посещён» и добавить **галерею** landscape-артов.

**Галерея локации** (арты `https://vlad-vechkanov.com/azlanti/Arts/<slug>.webp`, 16:9): блок `<div class="loc-media" data-gallery>` перед `<div class="entry">` — `loc-hero` (первый кадр) + `loc-thumbs` (остальные). Кириллица в имени файла → percent-encode (`lesnaya-zhizn%D1%8C.webp`). Лайтбокс уже есть (`setupGallery` в wiki.js). Портрет-плейсхолдер из aside при этом убрать. **Только посещённые** локации получают арт; проверь URL curl'ом заранее.

**Обязательно каждый раз:**
- **Лендинг** `index.html`: последняя/следующая сессия, «Мы здесь», абзац «Где мы сейчас», футер `sidebar-foot`, счётчик NPC.
- **Зацепки** `leads.html`: обновить/заменить устаревшие блоки-callout, добавить новые; таймеры (`callout warn` с ⏳); дату в meta-бейдже.
  > ### ⚠️ ЧТО ТАКОЕ ЗАЦЕПКА (прогоняй КАЖДУЮ по этому тесту)
  > Зацепка — конкретное **действие/шаг**, которое партия реально пойдёт делать, и понятно **ЧТО** делать и **ЗАЧЕМ**. Тест: формулируется ли как «пойти к X / сделать Y / успеть к сроку Z», и ведёт ли куда-то? Если да — зацепка.
  > **НЕ зацепка** (частые ошибки свежих агентов):
  > - **Противник / фракция** сам по себе («Адская свора») — у него своя страница; зацепка = конкретное действие против него («собрать доказательства преступлений Нессиана»), а не сама фракция.
  > - **Предмет** сам по себе (дневник, клык, кольцо) — не зацепка; зацепка = **цель**, которой предмет служит («узнать, как вскрыть пластину»); предмет упоминается внутри.
  > - **Решение / открытое состояние** («куда девать пленных») — не зацепка.
  > - Уже решённый итог; место само по себе; формулировка про будущее («в СN сделаем»); дубликат другой зацепки.
  > Хорошие: «Статуэтка Ирори → пойти к Лисенгу»; «Оуб → отчитаться к ~14 Эрастуса»; «Спектакль → прийти через 6 дней».
  > Перед публикацией прогони **каждый** пункт индивидуально этим тестом (можно отдельным субагентом). Каждая зацепка — 1–2 строки (≤180 симв), контекст живёт на связанной странице, а не в лиде. См. [[feedback_leads_definition]].
- **Грид** `npcs.html`: запись `{ name, href, portrait|null, ph:"none"|"unknown", desc, place, status, sess }` за каждый новый NPC.
- **wiki.js**: счётчики (`count:`) в nav; записи в `INDEX` (поиск) за каждую новую страницу; `footer.state` («Данные на Сессию №N»).
- Для org-страниц — карточку в `orgs.html`.

## Шаг 4. Проверка

Python-скриптом: **0 битых внутренних ссылок** (все `href="(npc|loc|org|art|lore)-*.html"` существуют), `node --check assets/wiki.js` и инлайн-JS грида `npcs.html` валидны, все новые файлы на месте, счётчики сходятся.

## Шаг 5. Коммит → пуш → сводка

Порядок именно такой: Влад смотрит вики по **живым ссылкам**, поэтому пушить надо ДО сводки — иначе ссылки не открываются и проверить нельзя.

1. `git add -A && git commit && git push` (heredoc, футер `Co-Authored-By: Claude Opus 4.8 <noreply@anthropic.com>`). Пушить сразу — не ждать «ок».
2. Показать Владу **читаемую сводку** (не сырой дифф — он его не любит): таблица новых страниц (файл · портрет ✅/✕/❔ · суть) + список изменённых, где у **каждого** файла коротко сказано **что и в какую часть** внёс (событие / lead / инфобокс / связи / статус). Не бросать голый список файлов. Файлы — **кликабельными ссылками на живой сайт** (`https://wiki.vlad-vechkanov.com/<file>`, деплой ~30 сек).
3. Правки после ревью — просто ещё один коммит+пуш.

## Модели сабагентов

- **Разбор транскрипта и факт-чек — sonnet** по умолчанию. На С11 sonnet прочитал ~3700 строк, вытащил канву/NPC/события/зацепки и сам поймал канон-расхождения — тянет.
- **Факт-чек-проход по сквозным NPC** (участие в ≥4 сессиях) гнать отдельно на **Opus** — см. [[feedback_central_npc_factcheck]]. Там sonnet чаще галлюцинирует тонкие детали (подтипы существ, точные числа, «озвучено vs ГМ-заметка»).
- Haiku — **никогда**.
- Слабые места sonnet (тонкие канон-различия, разграничение слух↔заметка) страхует **Шаг 2 — обсуждение с Владом**: это встроенный человеческий контроль, он важнее выбора модели.
