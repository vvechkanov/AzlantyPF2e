# Арка 1 — Детектив: улики на Освальда

**Цель:** A ∩ B → Освальд + Староста. (A ∩ B) ∩ C → только Освальд.

> Калигни заходят **с севера (горы/штольни)**. Освальд **не бегает ночью** — он заранее выбирает слабые точки и подталкивает людей к действиям/разговорам.

---

|                  | **A — Риторика смирения**       | **B — Слабые замки**                                          | **C — Комплектность**                       |
| ---------------- | ------------------------------- | ------------------------------------------------------------- | ------------------------------------------- |
| **Суть**         | «Не лезьте, потери терпимые»    | Калигни бьют в точки со слабыми замками; кто-то знает изнутри | Крадут комплектами, как по списку снабжения |
| **Указывает на** | Староста, Мерра, Освальд, Брант | Освальд, Староста, Кузнец, Плотник, дети                      | Все кто работает с товарами (НЕ староста)   |
| **Пересечение**  | A ∩ B = Освальд + Староста      |                                                               | C срезает Старосту → **Освальд**            |
