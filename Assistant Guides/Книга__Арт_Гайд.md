# Книга Азланти — Гайд по генерации артов

> Инструмент: **Gemini** (генерация изображений)
> Стиль: **ink + light wash на пергаменте** — "полевые зарисовки наблюдателя"
> Нарративное обоснование: см. `Книга__Рассказчик_Тирос.md` → раздел "Зарисовки в тексте"

---

## Стиль — ключевые фразы для каждого промпта

Базовая стилевая строка (копировать в каждый промпт):
```
Loose confident dark brown ink linework with minimal watercolor washes. Ink splatters on paper edges. Muted earth tones. Aged parchment background. No text, no annotations.
```

Для **портретов** добавлять:
```
The style of a field naturalist's observational sketch. Bust portrait, head to mid-chest.
```

Для **боевых сцен** добавлять:
```
The energy of a manga action panel combined with a field naturalist's sketch style. Speed lines, dynamic diagonal composition.
```

Для **групповых сцен** добавлять:
```
Wide horizontal composition, all characters clearly visible.
```

---

## Работа с референсами

**Главное правило:** к каждому запросу прикреплять скетч-портреты персонажей (те, что мы сгенерили в стиле ink+wash), НЕ оригинальные арты игроков. Gemini лучше подхватывает лица, когда референс уже в целевом стиле.

**Формат подачи референсов:**
```
The N attached images are character sketches — use them as face/appearance references. All characters must appear in the scene and match their references.

Image 1: [Имя] — [краткое описание]
Image 2: [Имя] — [краткое описание]
...
```

**Для одного персонажа:**
```
Use the attached image as a character reference. Draw this exact person in a completely different style.
```

## Правила и лайфхаки

### Что работает:
- **"No text" повторять 2-3 раза** в промпте (начало, середина, конец) — иначе Gemini рисует тарабарщину
- **Рассадку задавать явно** слева направо для групповых сцен
- **Описывать действие каждого персонажа** — иначе все сидят одинаково
- **"Draw this exact person in a completely different style"** — ключевая фраза для переноса лица из референса
- **Скетч-портреты как референсы** лучше оригинальных артов (уже в целевом стиле)
- **Правки в том же чате:** "Keep everything exactly the same, only change X" — работает

### Что НЕ работает:
- Итеративное добавление персонажей (Gemini перерисовывает всё) — **НЕ ПРОВЕРЕНО, гипотеза**
- Голубая кожа для Гельдалы (нужно явно запрещать: "not blue")
- "Field journal" в промпте (провоцирует текст на полях)
- Слишком длинные промпты с деталями каждого персонажа (Gemini теряет фокус)

### Типичные проблемы и фиксы:
| Проблема | Фикс |
|---|---|
| Gemini игнорирует цвет глаз | Цвет в CAPS + повторить отдельно |
| Кожа не того оттенка | "(not X, not Y — specifically Z)" |
| Текст на картинке | "No text, no annotations, no writing, no labels" в начало и конец |
| Персонажи сливаются | Задать позу/действие каждому + рассадку L→R |

## Шаблоны промптов

### Портрет персонажа
```
Use the attached image as a character reference. Draw this exact person in a completely different style.

A quick ink and light wash portrait sketch on aged cream parchment paper. [ОПИСАНИЕ ПЕРСОНАЖА]. His/Her face must match the reference — same bone structure, same features. [ВЫРАЖЕНИЕ ЛИЦА / НАСТРОЕНИЕ]. Rendered in loose confident dark brown ink linework with minimal watercolor washes. Bust portrait, head to mid-chest. No text, no annotations. Ink splatters on paper edges. Muted earth tones. The style of a field naturalist's observational sketch.
```

### Боевая сцена (1-2 персонажа)
```
Use the attached images as character references. Image 1 is [КТО]. Image 2 is [КТО].

A quick ink and light wash action sketch on aged cream parchment paper. [ОПИСАНИЕ МОМЕНТА]. Speed lines [ОТКУДА]. [ДЕТАЛИ ДИНАМИКИ]. The faces must match the references. Loose confident dark brown ink linework with minimal watercolor washes. Ink splatters on edges. The energy of a manga action panel combined with a field naturalist's sketch style. No text, no annotations. Dynamic diagonal composition. Muted earth tones. Aged parchment background.
```

### Групповая сцена (3-5 персонажей)
```
The N attached images are character sketches — use them as face/appearance references.

Image 1: [Имя] — [краткое описание]
[...]

A quick ink and light wash sketch on aged cream parchment paper. [ОПИСАНИЕ СЦЕНЫ]. 

[Рассадка/позиции слева направо с действием каждого].

Each face must match its reference sketch. Loose confident dark brown ink linework with minimal watercolor washes. No text, no annotations. Ink splatters on paper edges. Muted earth tones. Aged parchment background. Wide horizontal composition, all N clearly visible.
```

### Точечная правка
```
This is perfect, keep everything exactly the same — same composition, same style, same faces, same poses. The only change: [ЧТО ИЗМЕНИТЬ]. Everything else stays identical.
```

## Pipeline

1. Выбрать сцену из текста книги
2. Определить персонажей в сцене
3. Собрать скетч-референсы этих персонажей
4. Выбрать шаблон (портрет / бой / группа)
5. Заполнить шаблон деталями сцены
6. Прикрепить референсы + промпт → Gemini
7. При необходимости — правка в том же чате
8. Результат → сохранить
