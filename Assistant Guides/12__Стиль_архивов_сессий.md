# Стиль архивов сессий

Гайд по оформлению полевых записей Тироса (НС-0774-КА) — архивных версий сессий PF2e кампании «Азланти». Решения основаны на сравнении С0 и С1 как наиболее удачных образцов; сформулировано в обсуждении 1 мая 2026.

Голос самого Тироса — отдельная тема, см. `Книга__Рассказчик_Тирос.md`. Этот гайд только про структуру и оформление.

## Имя файла

`С[N]-архив.md` — где N номер сессии. Лежит в папке соответствующей сессии: `Sessions/Session[N]/С[N]-архив.md`.

С0 и С1 переименовать постепенно, по случаю.

## Структура файла

```markdown
# Полевые записи — Дело НС-0774-КА

> **Локация:** [где происходит]
> **Дата:** [по календарю Голариона + AR]
> **Период:** [конкретный отрезок: «ночь 12–13 Гозрана, утро»]
> **Погода / контекст:** [короткий комментарий с характером Тироса, опционально]

---

## Запись первая: Название

[опционально жирная строка с датой/временем — см. ниже]

Текст записи.

---

## Запись вторая: Название

Текст записи.

---

[…]

---

_[Конец записи №N]_

_НС-0774-КА, полевой наблюдатель, Скрипторий Боньярда_
```

## Заголовок

Всегда `# Полевые записи — Дело НС-0774-КА`. Без подзаголовка «(продолжение)» даже когда сессия хронологически продолжает предыдущую — каждый архив самостоятелен.

## Шапка-цитата

Четыре поля. Все жирным:

- **Локация** — географическая точка или маршрут со стрелкой: «Гринфорд», «Хартвик → Гринфорд».
- **Дата** — по календарю Голариона + AR: «12 Гозрана, 4726 AR».
- **Период** — конкретный временной интервал: «ночь 12–13 Гозрана, предрассветные часы», «утро 12 Гозрана, около часа после рассвета».
- **Погода / контекст** — опционально, короткий комментарий с характером Тироса. Это его голос, не сухой регистр. Пример: «средиземноморская теплынь, около восемнадцати градусов. Для козодоя — терпимо, хотя ветер с реки мог бы быть и посвежее».

Поля «Наблюдатель» / «Объекты наблюдения» / «Примечание» — НЕ использовать. Тирос всегда наблюдатель (это в подписи), объекты считываются из текста, инструкции себе он не пишет.

## Записи

`## Запись N: Название` — где N прописью («первая», «вторая», «третья»...). Название короткое, образное, отражает суть записи: «Шестая гостья», «Операция», «У травницы», «Бой».

**Нумерация — внутренняя для каждого архива.** В каждом новом отчёте начинается с «первой». Сквозной нумерации между сессиями нет.

**Укрупнение.** Запись — это не сцена за столом, это укрупнённый смысловой блок. Ориентир — 4–7 записей на сессию. Если в исходнике 8+ сцен — группировать по логике (приход + допрос = одна запись; бой + добивание = одна; и т.д.). 8 «записей» в одном архиве — признак, что мелко нарезано.

## Жирная строка под заголовком записи

Опционально. Если запись чётко привязана ко времени и месту — ставить:

```markdown
## Запись пятая: Операция

**Ночь 11–12 Гозрана, между вторым и третьим часом. Гринфорд.**

Крик разорвал ночь...
```

Если запись охватывает плавающий промежуток или диалог без жёсткой привязки — не ставить, переходить сразу в текст.

## Авторские ремарки Тироса

**Встраивать в текст, не обособлять.** Никаких `_(Отмечаю: ...)_` или `*(...)*`. У Тироса нет двух регистров — он не следователь, переключающийся на «личное». Он один: одновременно наблюдает, фиксирует, шутит, путается. Обособление навязывает ему дисциплину Шерлока, которой у него нет, и ломает голос на швы — особенно слышно при озвучке в YouTube.

Короткие побочные мысли можно убирать в обычные круглые скобки без курсива:

> ...запечённая гречка с мясом, овощной салат, свежий хлеб, нарезки сыра. (Хлеб, к слову, был хороший. Плотный, с корочкой, с лёгким привкусом чего-то орехового. Я бы записал это в форму, если бы в форме была графа «хлеб».) Анканто подбежал к столу с энтузиазмом ребёнка...

Это тоже встраивание — просто с лёгким понижением голоса, графически почти не выделяется, ритмически работает как пауза.

## Прямая речь

Через тире, как в обычной русской прозе:

```markdown
— Можно поговорить, остановитесь, мы уже всё разрешили со старостой!

Он говорил это охотнику и лесорубу, не Дариусу.
```

**Italic для реплик не использовать.** В частности, не делать `_Время пришло?_ — спросил.` — только `— Время пришло? — спросил.`

Italic в тексте оставлять для других задач (нечеловеческие звуки, шёпоты-неречь, мысленная коммуникация — если возникнет нужда).

## Разделители между записями

`---` после каждой записи. Структурируют большие архивы и работают как маркер «здесь Тирос дописал блок и взял паузу». Без них при 5+ записях текст сливается в стену.

Перед концовкой `[Конец записи №N]` — тоже разделитель.

## Концовка

```markdown
---

_[Конец записи №N]_

_НС-0774-КА, полевой наблюдатель, Скрипторий Боньярда_
```

N — общее число записей в этом отчёте.

## Italic-обёртка

Через подчёркивания `_..._`, не звёздочки `*...*`. Рендер одинаковый, но в исходнике подчёркивания менее визуально шумные. Касается подписи и любых italic-фрагментов в тексте.
