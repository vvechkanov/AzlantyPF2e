## Озвучка — ElevenLabs

Рассказчик Тирос. Настройки утверждены Владом (август 2026), скриншот из веб-интерфейса.

| Параметр | Значение |
|----------|----------|
| **Voice** | **Носой 3** |
| **Model** | **Eleven Multilingual v2** |
| Speed | ~0.76 по ползунку (чуть быстрее середины, ≈1.05–1.10) |
| Stability | ~0.70 (ближе к «More stable») |
| Similarity | ~0.70 (ближе к «High») |
| Style Exaggeration | ~0.30 (ближе к «None») |
| Language Override | **выкл** |
| Output Format | **MP3 44.1 kHz, 128 kbps** |
| Speaker boost | **вкл** |

Логика набора: голос сухой и ровный — Тирос не играет, он фиксирует. Отсюда высокая стабильность и низкое Style Exaggeration. Ирония в тексте, не в интонации.

**Почему v2, а не v3:** v3 экспрессивнее, но менее предсказуем на длинных формах. Для 6-минутного монолога важнее, чтобы голос не поплыл к пятой минуте.

**Альтернативы, если понадобится сравнить** (август 2026): Gemini 3.1 Flash TTS — #2 по ELO при ~⅓ цены, но русский неровный; MiniMax Speech 2.6/2.8 — хвалят за стабильность на длинных формах. ElevenLabs остаётся эталоном для нарратива и характерных голосов.

## Арты

Стиль пересказов: **ink + light wash по состаренному пергаменту**, тёмно-коричневый контур, приглушённые земляные тона, брызги чернил по краям. Это не парадный стиль портретов кампании — это полевой блокнот наблюдателя.

Существующие портреты NPC/PC (painterly, прозрачный фон, `/azlanti/portarits/`) в ролик **не вставляются напрямую** — они идут как character reference, чтобы перерисовать лицо в ink+wash и сохранить узнаваемость.

Порядок генерации: сначала портреты-референсы, потом сцены с ними, пейзажи и натюрморты — параллельно в любой момент.

Правила генерации, ретраев и лимитов — общие для кампании, см. автопамять (`feedback_art_retries`, `feedback_image_model_pro_only`).

## Тайминг

Расчёт хронометража: **1,96 слова в секунду**.

Цифра замерена, а не взята из головы: озвучка ролика 1 — 880 слов текста раскадровки на 448 секунд mp3 (ElevenLabs, Носой 3, speed 1.08). В знаках — 12,8 знака/с с пробелами.

Готовый ролик вышел 7:46 при 7:28 озвучки, то есть монтаж добавляет ещё **+4%** паузами, титрами и хвостами кадров. Итоговая формула:

```
секунды ролика = слова / 1,96 × 1,04
```

⚠️ До сентября 2026 в гайде стояло 2,3 сл/с — эта цифра занижала хронометраж на 17%. Ролик 1 планировался на 6:20, вышел 7:46. Если где-то встретится старая формула — это ошибка.

Кадр держит внимание 8–20 секунд. Всё, что длиннее 25 секунд на одной картинке, надо дробить на планы (общий → лицо → деталь) или подпирать движением камеры.

## Структура файлов

**Один ролик — одна папка.** Сессия даёт несколько роликов: С0 — это записи 1–7 из архива, из которых ролик 1 покрыл только запись первую.

В волте, рабочие файлы:

```
Sessions/Session0/Видео/
   01__Хартвик__текст.md
   01__Хартвик__раскадровка.md
   01__Хартвик__промпты.md
   02__Дорога_в_Гринфорд__раскадровка.md
   02__Дорога_в_Гринфорд__промпты.md
```

Вне волта, медиа:

```
C:\Azlanti\Video\
   Session0\
      01__Хартвик\            кадры, art\, audio\, video\, paper\, _старые\
      02__Дорога_в_Гринфорд\
   References\                портреты персонажей, кропы сцен — общие на все ролики
```

Арты из прошлых роликов **не копировать** в новую папку — линковать из Resolve по старому пути и помечать в раскадровке как `[АРТ ↺ shotNN]`.
