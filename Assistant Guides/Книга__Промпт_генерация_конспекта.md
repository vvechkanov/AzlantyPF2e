# Промпт: генерация блоков конспекта после главы

**Когда использовать:** в том же чате, где только что написана глава Книги Азланти (ПСN_книга.md). Модель ещё «в голосе Тироса» — сразу кидаешь ей этот промпт.

**Что получится:** три блока Markdown (ДОСЬЕ / ХРОНИКА / ОГРАНИЧЕНИЯ). Копируешь и приносишь в основную рабочую сессию со мной для мерджа.

---

## Промпт (копировать целиком)

```
Теперь, оставаясь в контексте только что написанной главы, сгенерируй ТРИ блока для накопительного конспекта Книги Азланти. Они нужны, чтобы будущие главы писались в свежем контексте, но Тирос не терял память — свои оценки персонажей, речевые привычки, открытые нити и зафиксированные детали.

Пиши максимально компактно. Это не пересказ главы, а концентрат. Без преамбулы, без объяснений структуры — только три блока.

=== БЛОК 1: ДОСЬЕ (голос Тироса) ===

От первого лица, голосом Тироса. Сухо, точно, без пересказа событий. Только то, что Тирос СЕЙЧАС думает/знает о каждом подопечном с учётом этой главы. Включай только тех, кто появлялся в главе или чьё восприятие изменилось.

### [Имя]
- **Как вижу сейчас:** 1-2 строки. Текущее отношение Тироса — с уместной иронией, ворчанием, неохотной симпатией.
- **Речевые/поведенческие привычки:** конкретные жесты, обороты, манеры, которые Тирос уже зафиксировал. Буллетами.
- **Что цепляет/беспокоит:** одна строка, если есть.

### Группа в целом
Одна-две строки о динамике: кто к кому тянется, где трения, где неожиданные связки.

=== БЛОК 2: ХРОНИКА (факты, без голоса) ===

Сухо, без Тироса. Для сверки фактов.

### Глава N: [короткий тег]
- **In-game время:** [дата/период]
- **Место:** [локация]
- **Ключевые события:** 3-6 буллетов, по одному предложению
- **Открытые нити (новые):** что заложено и не закрыто
- **Закрытые нити:** что разрешилось
- **Якорные детали:** конкретные вещи из ТЕКСТА главы, на которые Тирос ссылался и которым нельзя противоречить потом. Примеры: «медная пуговица на хвосте», «Кэррен держит топор в левой», «Самум не отрывает ступни от земли при движении», «Анканто просил не убивать — и его слушались».

=== БЛОК 3: ОГРАНИЧЕНИЯ (что Тирос ещё НЕ знает) ===

Буллетами — зоны, куда Тиросу на конец этой главы внутрь лезть нельзя (только внешнее поведение):
- [персонаж] — [какая внутренняя зона/секрет закрыта]
```

---

## Заметки по использованию

- Если по персонажу ничего не изменилось — не включай его в ДОСЬЕ. Меньше шума при мердже.
- Якорные детали — самое важное. Без них голос Тироса в будущем разъедется.
- Блок ОГРАНИЧЕНИЯ нужен, чтобы ГМ мог проверить: не лезет ли будущая глава в зону, которую Тирос видеть не должен.
