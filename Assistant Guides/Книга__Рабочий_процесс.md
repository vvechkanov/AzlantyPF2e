# Книга Азланти — Рабочий процесс

## Где генерировать

**Только в Incognito Chat.** Не в проекте, не в обычном чате. Проектный контекст (статблоки, шаблоны NPC, словари) и userMemories давят на стиль генерации, превращая живой голос Тироса в конспект. Incognito = ноль памяти, ноль контекста, только промпт.

## Промпт

Файл: `Assistant Guides/Книга__Project_Instructions.md` — вставлять целиком в начало Incognito-чата.

## Цикл работы

1. Открыть Incognito Chat
2. Вставить промпт из `Книга__Project_Instructions.md`
3. Отправить рекап сессии целиком + список нераскрытых секретов
4. Согласовать план сцен (3–6 на главу)
5. Дальше — по одной сцене: кусок транскрипта/рекапа → генерация → фидбек → следующая
6. Собрать готовые сцены в `Sessions/SessionN/ПСN_книга.md`

## Почему кусками

- Короткие генерации держат голос Тироса живым
- На длинных дистанциях голос сползает в конспект
- Короткий входной материал = меньше шума = чище результат
- Одна сцена = 400–800 слов

## Подтверждено

Тест от 23.03.2026: генерация в Incognito с новым промптом дала радикально лучший результат, чем генерация внутри проекта Азланти. Голос Тироса живой, болтливый, с ремарками и отступлениями. Фрагментация исчезла.
