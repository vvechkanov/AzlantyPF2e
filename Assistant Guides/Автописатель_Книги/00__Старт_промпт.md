# Точка входа — скилл `book-chapter`

> Раньше здесь лежал промпт на 22 килобайта, который Влад копипастил в новый чат. Теперь процесс живёт скиллом и версионируется вместе с волтом.

## Как запускать

Сказать в чате: **«напиши главу по сессии N»** (или «книга по С{N}», «прогони сессию N в книгу», «автописатель N»). Скилл `.claude/skills/book-chapter/SKILL.md` подхватится сам и проведёт весь конвейер.

Отдельный чат на главу по-прежнему обязателен: main author не должен накапливать контекст между сессиями. Память переносится через `Lessons.md`.

## Почему копипаст-промпта больше нет

Он дублировал `00__Архитектура.md` и `01__Шаблон_брифа.md`. Две копии процесса неизбежно расходятся, и в какой-то момент главу начинают писать по устаревшей. Теперь описание одно: архитектура — «почему так», скилл — «что делать по шагам».

## Перед запуском проверить

**Конспект Тироса доведён до конца сессии N-1.** Раздел «Свежая глава» в `Сюжет кампании/Книга__Конспект_Тироса.md` должен быть про предыдущую сессию. Если нет — глава заблокирована, сначала достраивается память рассказчика.
