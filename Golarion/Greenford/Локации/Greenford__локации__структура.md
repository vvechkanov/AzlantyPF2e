# Greenford — структура локаций (шаблон)

Этот файл — **шпаргалка-форма** для заметок по локациям Гринфорда: гостиницы, таверны, лавки, мастерские, общественные места.

## Как именовать файлы локаций
- Имя файла = **короткое название места**, как его будут говорить вслух.
- Если есть английское/официальное — держим его в заголовке в скобках.
- Дубли избегаем: в Гринфорде лучше, чтобы названия были уникальны.

Пример: `Лесная жизнь.md` (а в заголовке — *The Life and the Forest*).
