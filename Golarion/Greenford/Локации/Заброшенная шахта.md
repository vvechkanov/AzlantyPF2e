# Заброшенная шахта

**Расположение:** предгорья, ~20 минут пешком на восток от [[Greenford__деревня|Гринфорда]]
**Статус:** заброшена ~15 лет назад

## Описание
Холм, к которому пристроена деревянная стена (~15 футов высотой) с воротами (~12 футов). Ворота не заперты, покосившиеся, прикрыты. Всё пыльное, заброшенное — но не полностью забытое.

Внутри — покосившаяся шахтная дорога с рельсами для вагонеток, уходящая вглубь. Всё разграблено: металлические части вынесены, вагонетка сломана, остались куски дерева и камня.

## Обитатели

### Паутинщики и пауки (верхний этаж — «Паучье гнездо»)

**Состав:** 3× Web Lurker (Level 3), 2× Spider Swarm (Level 0), 2× Hunting Spider (Level 1)
**XP:** 170 (Severe+ для 5 игроков 3 уровня)

**Механика охоты** (d6 при приближении партии):
- 1–3: все три паутинщика на месте, полный состав
- 4–6: один ушёл на охоту → второй d6 определяет кого взял с собой, d4 — через сколько часов вернётся (заходит с тыла если бой ещё идёт)

**Тактика:** координация через Spider Speak. Один блокирует проход, второй кидает паутину с дистанции, третий заходит с фланга. Рои — тыл, Hunting Spider — авангард. Hazard'ы на подходах: Web Lurker Noose (удавка из паутины), Web Lurker Deadfall (обвал камней по растяжке).

### Калигни (нижние уровни → анклав)
- Через шахту проходят к поверхности. [[Курзаир]] — единственный, кто общается с паутинщиками (через Акло).
- Подробности: [[03__Данж_к_анклаву_калигни|Данж: путь к анклаву]]

## Что известно партии (по итогам Сессии 2)

**Из разговора с [[Ник|Ватагой Ника]]:**
- Калигни уносят украденное в горы, к старой шахте
- Дети пытались зайти — пауки агрессивно встречают, но не преследуют за периметр
- Шахта заброшена ~15 лет

**Из визита партии (12 Гозрана):**
- [[Гельдала (Егорушка)|Гельдала]] договорилась с паутинщиками на паучьем языке
- Условие прохода: идти строго по рельсам, не сворачивать
- Легенда для калигни: Гельдала «избила» паутинщика и распугала пауков
- Партия решила вернуться со свитками Comprehend Languages (прибывают вечером 12 Гозрана)
