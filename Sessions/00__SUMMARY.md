# Sessions — SUMMARY
Путь: `Sessions`

Здесь лежат материалы по сессиям кампании: заготовки, транскрипты, нарративы, саммари.

---

## Структура

Каждая сессия — отдельная папка:

```
Sessions/
├── Session0/          ← Пред-сессии (до старта кампании)
│   ├── ПС1_transcript.md
│   ├── ПС2_заготовка.md
│   └── ...
├── Session1/          ← Первая полная сессия
│   ├── заготовка.md
│   ├── transcript.md
│   ├── narrative.md
│   └── summary.md
├── Session2/
│   └── ...
└── 00__TODO_*.md      ← Общие чеклисты
```

Внутри каждой папки могут быть:
- `заготовка.md` — план/сценарий сессии (до игры)
- `transcript.md` — очищенный транскрипт аудио (после игры)
- `narrative.md` — нарратив по транскрипту
- `summary.md` — краткое саммари

Для пред-сессий: файлы с префиксом `ПС1_`, `ПС2_` и т.д.
