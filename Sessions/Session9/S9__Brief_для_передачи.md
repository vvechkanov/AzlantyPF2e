### 2.2. HUB.d2 — центральная схема кампании

**Путь:** `C:\DND\sync\Sync\Obsidian\PF2e\Кампейны\Азланти\00__HUB.d2`

**Структура:**
- **Root уровень** — крупные сущности (Library, HouseOfHealing, Arcanamirium, HouseOrmuz, HouseBlakros, Pathfinders, Syrvas), а также источники (Sources с PC и артефактами) и большие связи между ними
- **Layers** — детальные карты по каждой крупной сущности (`layers.house_of_healing`, `layers.arcana`, `layers.ormuz`, `layers.blakros`, `layers.pathfinders`, `layers.syrvas`, `layers.library`, `layers.puddles`)
- **Цветовое кодирование нитей:** classes thread-plates (лазурная, пластины), thread-anchanto (золотая, Анканто), thread-statue (сиреневая, статуэтка Кирана)

**Стандартный паттерн обновления (как сделано для library и house_of_healing):**
1. Root-узел получает `link: "obsidian://open?vault=PF2e&file=<путь к Obsidian-файлу>"` (а не на layer)
2. Layer переписывается: внутри блока — NPC с link на файлы, внутренние связи, потом внешние сущности с пометкой `_ext`, потом внешние связи

**Пример — что выглядит готовый блок (layers.house_of_healing):**
```d2
house_of_healing: {
  HoH: "🕊️ Дом Исцеления..." {
    link: "obsidian://open?vault=PF2e&file=..."
    Zharichela: "👑 Жарикела..." { link: "..." }
    Doris: "Дорис Кай..." { link: "..." }
    Ileya: "..." { link: "..." }
    Keyin: "..." { link: "..." }
    HealingRaft: "⛵ Healing Raft..."

    # Внутренние связи
    Zharichela -> Doris: "духовный наследник" {style.stroke-dash: 3}
    Doris -- Ileya: "друзья, спор без злобы"
    Doris -- Keyin: "союзники-активисты"
    ...
  }

  # Внешние сущности (с _ext в имени)
  TempleShiningStar_ext: "..." { link: "..." }
  Yamtar_ext: "..." { link: layers.ormuz }
  ...

  # Внешние связи
  HoH.Doris -- Yamtar_ext: "..."
  ...
}
```

## 6. Стилевые правила

### Локация
- **Сенсорно**: запах, шум, свет, ориентир — обязательно для секций «Снаружи» и «Внутри»
- **Зонирование внутри** — если место большое (вестибюль / зал / тыловая часть)
- **Расписание утро/день/вечер/ночь** — обязательно
- **1d4–1d8 случайных сцен** — для оживления
- **Примечания ГМ** — конкретные подсказки (не общие фразы), какие сцены играть редко, какие часто
- **Связи** — не «вижу что есть в Obsidian», а **сюжетные связи** (через кого нити, кто союзник, кто враг)

- **Картинка `![|300](TBA)`** в начале — placeholder
